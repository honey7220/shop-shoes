# GOLDSOLE

한정판 스니커 리셀 쇼핑몰 (단일 `index.html` + `img/`).

## 기능
- 회원가입/로그인, 장바구니, 결제(체험용)
- 등급별 포인트 적립(브론즈 1% ~ 블랙 12%), 포인트 유효기간(구매 1년·가입 3개월), 신규 가입 쿠폰
- 사이즈 230~290(5mm) 재고, 상품 표 / 재고 표 분리, 주문 시 재고 차감
- 상품 상세 설명, 사이즈 가이드, 사이즈별 시세·거래 내역, 배송 완료 후 리뷰(500P)
- 주문 상태: 검수 대기 → 검수 중 → 검수 합격(S/A/B 등급) → 배송중(송장) → 배송 완료
- 주문 취소 / 검수 불합격 환불: 재고 복원, 사용 포인트·쿠폰 복원, 적립 포인트 회수
- 이용약관, 개인정보처리방침, 청약철회·환불 안내 (푸터)
- 링크 미리보기(OG) 이미지 `img/og.png`

## 관리자
푸터의 `관리자` 버튼 → 상품 표 / 재고 표 / 주문 관리 / 입출고 기록 (데모 비밀번호는 `index.html`의 `ADMIN_PASS`).

## 수정 위치
- 상품·재고 초기값: `PRODUCTS`, 상품 설명: `INFO`
- 등급·적립률: `TIERS`, 유효기간·쿠폰·리뷰 보상: `POINT_EXP_DAYS`, `WELCOME_COUPON` 등
- 사업자 정보·약관 문구: `SITE`, `POLICIES`

## 데이터 설계
`data/schema.sql` (표 구조와 예시 쿼리), `data/products.csv`, `data/inventory.csv`

> 데이터는 브라우저 localStorage에 저장되는 체험용입니다. 실제 운영 시 서버·DB, PG 연동, 사업자 정보 입력과 약관 법률 검토가 필요합니다.
